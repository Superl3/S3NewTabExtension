# Dock Manual Test Checklist

## 1) 스크롤 고정
- [ ] 페이지 스크롤/컨텐츠 이동 중에도 Dock은 하단 고정 위치를 유지한다.
- [ ] 창 크기 변경 후에도 Dock은 하단 중앙에 유지된다.

## 2) 표시 모드별 보드 영향
- [ ] `Always visible` 모드에서는 Dock 높이만큼 보드 하단 패딩이 반영되어 컨텐츠가 가려지지 않는다.
- [ ] `Hover` 모드에서는 보드 하단 패딩이 0으로 유지되어 보드 사이즈가 줄지 않는다.
- [ ] Dock 비활성 시 하단 패딩이 0으로 복귀한다.

## 3) overflow
- [ ] Dock 아이템이 많아지면 strip이 가로 스크롤된다.
- [ ] wheel 스크롤이 strip 가로 이동으로 동작한다.
- [ ] overflow 시작/중간/끝에서 fade 상태가 올바르게 바뀐다.

## 4) 키보드
- [ ] Tab으로 Dock item과 Dock 액션 버튼에 순차 접근 가능하다.
- [ ] ArrowLeft/ArrowRight, Home/End 이동이 동작한다.
- [ ] Enter/Space로 활성 item 동작(페이지 이동 또는 설정 오픈)이 실행된다.

## 5) 다크 모드/테마 대비
- [ ] 밝은/어두운 배경에서 Dock 아이콘/텍스트/indicator가 식별 가능하다.
- [ ] 포커스 링이 배경과 충분히 구분된다.

## 6) 드래그-드롭 규칙
- [ ] 위젯을 Dock 영역에 드롭하면 보드가 아니라 Dock에 배치된다.
- [ ] Dock에 배치된 위젯은 보드 자동배치/페이지 계산에서 제외된다.
